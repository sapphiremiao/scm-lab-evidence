# Code review vs configuration audit

A code review is when a teammate checks one change before it is merged, like when I reviewed my pull request #2 and left a comment on the template file. A configuration audit is a bigger, formal check done by an independent team, usually before a release. The Functional Configuration Audit (FCA) checks that the product does what the requirements say, and the Physical Configuration Audit (PCA) checks that what was built matches its documents.
